## 画布与编辑器

| 决策 | 理由 | 来源 |
|---|---|---|
| 画布用 **React Flow**，引擎自持 | 遵循 editor↔engine 彻底解耦 | Rete.js / LiteGraph 的做法 |
| **端口类型强制校验 + 着色** | 消掉一整类接线错误 | Langflow |
| **节点 = 声明式 `ParamSpec` + runner** | Inspector 表单由后端 schema **泛型生成**，杜绝重复 | Langflow `inputs=[...]` |
| **节点卡片上的 description 内联可编辑** | 它是用户说「这一步干什么」的地方，**也是 AI 的输入**。藏进属性面板会把这个 App 最重要的字段藏起来 | 自定（产品核心） |
| 节点卡片**不 import store** | 保持纯展示组件（渲染便宜、好测） | 自定 |

## 编译器与图语义

| 决策 | 理由 | 来源 |
|---|---|---|
| **共享状态是主数据通道**，边只表达依赖 | 边传值解决不了跨分支、非相邻、循环累积 | LangGraph State+reducer / Flowise `$flow.state` |
| 分支节点**真执行**再条件跳转 | 决策进入时间线，**可观测性值一个 super-step** | 自定 |
| **循环强制上限** | 会循环的 agent 迟早会死循环 | Dify 50 节点上限 / Flowise Max Loop 默认 5 / LangGraph `recursion_limit` |
| **多条边进同一 input handle → 收成列表** | 这才让 Aggregator 能合并互斥分支 | 自定 |
| **`unbounded_cycle` 用 Tarjan SCC** | DFS 回边报哪个节点取决于遍历起点，**信息会误导人** | 自定 |
| **事件 emitter 用闭包捕获，不用 contextvar** | LangGraph 可能在自己的 task 里跑节点，contextvar **静默不传播**（症状只是"UI 看起来是死的"） | 实测踩过 |
| **`GraphBubbleUp` 原样放行** | `interrupt()` 靠抛它来暂停；吞掉会把暂停变成失败 | 实测踩过 |

## 节点

| 决策 | 理由 |
|---|---|
| **`retriever` 用 BM25 而不是向量** | 零依赖可跑。**代价是不能匹配同义词** —— docstring 里诚实标注 |
| **`agent` 用手写循环而不是现成 ReAct** | 每一步进时间线；工具调用失败可回灌给模型 |
| **`tool` 与 `agent` 都保留** | 区别是「**不由模型选工具**」——确定性调用有自己的价值 |
| **Code 节点 `requires_trust` + 全局开关** | 运行任意代码必须有第二道人工门 |
| **`human_input` 的幂等约束写在文件头** | checkpointer 恢复会**重跑整个节点** |
| **`loop` 的双保险**（`max_iterations` + `recursion_limit`） | 会循环的 agent 迟早会死循环 |

## AI 功能

| 决策 | 理由 | 来源 |
|---|---|---|
| **一律 accept/reject diff** | 静默改画布 = 图不可预测，**与可视化编辑器的目的相反** | n8n AI Builder / Langflow Assistant |
| **AI 输出必须过字段校验** | 保证 Inspector **永远能渲染** | 自定 |
| **NL→图用工具调用，而非吐 JSON** | 每次变更立即校验，模型编错**当场**收到反馈 | n8n / Langflow Assistant |
| **`repair-graph` 的完成判据是「校验通过」** | `generate-graph` 是「`finish` + 校验通过 + 试跑通过（外部错误除外）」；生成要防的不只是语法错，还有运行时才发现的分支/回边错误 | 自定 |
| **每轮把「剩余错误全文」回馈给模型** | 只回上次变更结果的话，模型得自己记住开头那份列表 —— 对话一长就记不住 | 自定 |
| **`severity` 默认只修 `error`** | 缺 End 是本项目的 **warning**；默认修复不该顺手加用户没要的节点 | 自定 |
| **diff 用 node id 判定身份** | 改个名字应显示「修改 1 个」而不是「删 1 + 增 1」—— 后者会让用户**不再相信这个 diff** | 自定 |
| **喂给模型的文本永远英文** | 否则**切界面语言会悄悄改变模型的推理** | 自定 |
| **AI 辅助功能不走 `ModelGateway`** | 它们是**平台功能**，花费属**平台预算**，不属于任何 agent 的成本；但仍通过 `ai_buildtime/metering.py` 计入公开额度 | 自定 |

## 能力层

| 决策 | 理由 |
|---|---|
| **统一形状**：ABC + 默认实现 + 进程级 `get/set` + `build` | **六个**已验证，**后续照抄，别另发明** |
| **纯函数不抽接口** | 无 I/O、无资源、无外部状态 → 抽了只是多一层间接 |
| **接口要暴露「调用」，不只是「构造」** | token 数**跟着响应回来**，统计必须在调用点。只暴露 `build_model()` 的话成本统计仍要在每个调用点各加一遍 |
| **失败必须关闭**（fail closed） | 静默降级会把「隔离坏了」变成「隔离被拿掉了」 |
| **未知配置值报错，不静默回退默认** | 同上 |
| **`usage_from_message` 返回 `None` 而不是零值** | 零值无法与「这个 chunk 没花 token」区分，merge 会把**调用次数算成 chunk 数** |
| **Agent 的用量要 `merge` 而不是 `=`** | 每次推理一步就一次调用，「这个节点花了多少」是一个**和** |

## 安全

| 决策 | 理由 |
|---|---|
| **认证默认开启，且不可被意外关闭** | `AUTH_MODE=local` + 非回环绑定 → **自动升级为 token**；无 token **拒绝启动** |
| **中间件而非逐路由依赖** | 依赖要「记得加」；中间件**默认关闭** `/api/*` —— **忘记做事是安全的** |
| **第二道防御：校验真实客户端地址** | 防「`SERVER_HOST` 写 127.0.0.1 但实际 bind `0.0.0.0`」 |
| **不透明 token，不是 JWT** | 没有第三方需要验签；自托管工具里**吊销**比无状态更重要 |
| **`hmac.compare_digest`** | 会泄漏时序的比较可以被**逐字符爆破** |
| **子进程 + Job Object**（不是线程 + `wait_for`） | **线程挡不住 CPU 死循环**；`wait_for` 放弃的是 await，核还被占着 |
| **从 builtins 移除 `getattr` 家族** | `getattr(o, "__cla" + "ss__")` 能绕过任何 AST 检查。**移除之后守卫才不是装饰品** |
| **`describe()` 只报「有没有」** | 一个「顺手把值也带上」的改动会让凭据进入日志 |
| ⚠️ **导出时 `trusted` 要重新确认** —— **尚未实现** | 画布上的 trusted = 「**我**接受以我的用户身份跑」；交给客户是另一件事。**但代码里没有这一步**：`runtime/export.py` 只有 `_strip_credentials`（处理凭证），`trusted` 原样写进导出物。**这是已知缺口，不是已做的决策** |

## 持久化

| 决策 | 理由 |
|---|---|
| **图存 JSON + SQLite 双写** | DB 是缓存，**文件是可 git 的产物** |
| **`runs.workflow_id` 故意不是外键** | 草稿图未保存也能运行 |
| **迁移两条路径 + 一致性守卫** | 已有库没有 `alembic_version` 行；测试要的是"当前 schema"而非"怎么到达的"。**守卫让两条路必须一致** |
| **`retired_at` 一个字段就是整个淘汰策略** | 「这个运行能不能丢」在一处有一句话的答案，而不是每个调用点重复状态列表 |
| **淘汰要「年龄 + 数量」双上限** | 年龄在高负载下**什么都限制不住**（窗口内 1000 个运行全是"新的"） |
| **transcript 先写、内存后裁** | 顺序承重：`_persist_finish` 要读 `bus.history()`，`_retire` 会裁掉它 |
| **`410 Gone` ≠ `404`** | 「去读历史」vs「你有 bug」的区别 |
| **`tweaks` / `recursion_limit` 落盘（不给默认值）** | 一次带 tweaks 的运行在恢复后走了默认配置，症状是「结果和上次不一样」而**没有任何东西报错**。`None` 只表示「这一行早于该列」，此时才退回配置默认值**并写日志** |
| **未保存工作流的运行，拒绝恢复而不是把图存进 `Run` 行** | 存进行里会让**行成为一份同时还在画布上被编辑的定义的权威**，两者不一致时无从判断哪份真的跑过 |
| **`RunStore.load()` 与 `summary()` 分开** | `summary` 是**线上形状**，与实时摘要**逐键对比**；把 `tweaks` 加进去既泄内部字段又会打破那个对比 |
| **`UtcDateTime` 修在列上，不修在每个读取方** | 偏移消失的原因**只有一个**且属于列。逐读取方修 = 每个读取路径一份知识副本（本项目已因此被咬过两次） |
| **`hydrate` 的 `created_at` 兜底是 `now(utc)` 而不是 `None`** | `RunContext.created_at` 是必填的，而 `load()` 理论上可能给出 `None` |
