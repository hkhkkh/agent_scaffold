FAQ

开始之前，你可能想知道。

需要注册或登录吗？

不需要。公开演示只需要通过一次人机验证，就可以直接打开编辑器。演示数据是共享的，请不要输入隐私内容。

可以运行 Code 节点吗？

公开演示出于安全考虑禁用了代码执行。含 Code 的模板可以完整查看，但 Run/Save 会禁用；本机私有部署可以开启完整能力。

每人每天能用多少？

匿名访客每天 3 次 AI 生成、2 次运行、50,000 tokens；同一 IP 还有一层更高上限的兜底额度。额度每天 UTC 零点重置，页面顶栏会显示剩余次数。

我的工作流会被别人看到吗？

公开演示为了让大家直接体验，工作流数据是共享的。删除、导入、导出和设置只对管理员开放；如果需要完全私有，请使用本机部署或私有服务器。

支持哪些模型和工具？

当前演示使用 DeepSeek，并内置联网搜索、HTTP 请求、数据库查询、文本处理等工具。工作流里也可以配置模型、工具和节点参数。

可以自己部署吗？

可以。项目是 FastAPI + LangGraph + React Flow，支持本机开发、独立数据目录和 Cloudflare Tunnel 公网演示。本机模式没有公开演示的额度与只读限制。
